Uso do aplicativo

O VEN é uma ferramenta de apoio para elaborar orçamentos e registrar vendas. Você é responsável pelas informações cadastradas (preços, impostos, dados de clientes) e pelo uso dos documentos gerados. O VEN não substitui sistema fiscal nem emite nota fiscal.

Seus dados e backup

Os dados ficam no seu aparelho. Perda, troca ou defeito do aparelho podem causar perda de dados; faça backups regularmente pela função “Baixar backup”.
