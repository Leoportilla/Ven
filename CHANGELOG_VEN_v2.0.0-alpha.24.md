# VEN 2.0.0-alpha.24

- Cadastro de clientes com campos separados para rua/avenida, número, complemento, bairro, cidade, UF e CEP.
- Geração de link de navegação para o Waze quando rua, cidade e UF estiverem preenchidos.
- Link para o Waze disponível na prévia do endereço e no cartão do cliente.
- Compatibilidade com cadastros antigos: o endereço legado permanece visível no campo Rua para edição, e o texto do endereço continua armazenado.
- `versionCode` 27; `applicationId` permanece `br.com.ven.app`.
